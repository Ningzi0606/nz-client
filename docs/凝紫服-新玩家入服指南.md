## 四、给管理员的检查清单（玩家看不到，可删）

本服已安装 **EasyWhitelist**（白名单改成**按名字判定**），加人**不需要重启服务器**。

### 加人三步

1. 玩家报名时登记**准确名字**（大小写），并让对方确认；
2. 控制台执行（注意大小写，和玩家客户端里填的完全一致）：

   ```
   easywhitelist add 名字
   ```

   提示 `Added xxx to the whitelist` 即成功，**立刻生效**，不用重启。

3. 玩家进服注册后，用 `/auth list` 确认账号已建立；不会注册的可代建：`/auth register 名字 密码`。

### 常用管理命令（全部按名字、全部区分大小写、全部即时生效）

| 目的 | 命令 |
|---|---|
| 加白名单 | `easywhitelist add 名字` |
| 移出白名单 | `easywhitelist remove 名字` |
| 给 OP | `easyop 名字` |
| 取消 OP | `easydeop 名字` |
| 封禁 / 解封 | `easyban 名字` / `easypardon 名字` |

> 说明：原版 `whitelist add 名字` 也还能用（校验已按名字），但它会先去微软查正版档案，网络不好时会卡 30 秒、还把正版 UUID 写进 json；**建议统一用 `easywhitelist add`**，不联网、秒回、大小写原样保留。
>
> 白名单 / OP / 封禁的 json 里每条仍要保留 `uuid` 字段（格式合法即可，内容不参与判定），这是 EasyWhitelist 的要求，命令会自动处理。

## 五、皮肤怎么弄（玩家向）

离线服服务器**不下发皮肤**，皮肤由客户端里的 **CustomSkinLoader** 从皮肤站按「名字」去查。客户端已配置成**优先 LittleSkin**。

### 五步搞定

1. 打开 <https://littleskin.cn>，注册账号（邮箱即可，免费）；
2. 登录后进「角色管理」→ 新建角色，**角色名 = 你的游戏名**（一字不差，大小写也尽量一致）；
3. 进「皮肤库」上传皮肤 PNG（64×64），选 Classic（粗手臂）或 Slim（细手臂）；
4. 回游戏，**重进服务器**；看不到就关掉游戏，删除 `客户端\game\CustomSkinLoader\caches` 文件夹再开；
5. 其他玩家也能看到你的皮肤——前提是他也用同一个完整客户端。

### 注意

- 皮肤站的角色名和游戏名对不上 = 查不到皮肤，一直是默认 Steve/Alex；
- 客户端有 30 分钟皮肤缓存，刚上传看不到是正常的，删缓存最快；
- 如果你的名字正好撞了某个正版账号名：客户端会先查 LittleSkin，没查到才会退回 Mojang，这时可能显示成那个正版号主的皮肤。想彻底避免，就上传皮肤 / 换个不撞车名字（换名字=换身份，慎用）；
- 只想自己看到皮肤（不给别人看）：把 PNG 放到 `客户端\game\CustomSkinLoader\LocalSkin\skins\你的名字.png`，这个只对本机生效。
