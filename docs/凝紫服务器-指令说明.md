# 凝紫服务器 · 指令使用说明

> 服务器版本：Minecraft 26.3 / Fabric
> 地址：`play.simpfun.cn:14039`
> 最后更新：2026-10-29

---

## 一、新玩家第一步

进服后先注册，否则动不了：

| 步骤 | 指令 | 说明 |
|---|---|---|
| 1 | `/register 你的密码 你的密码` | 首次进服注册，两次密码要一样 |
| 2 | `/login 你的密码` | 之后每次进服登录 |
| 3 | `/autologin set 你的密码` | 开启自动登录，以后免输密码 |

## 二、传送 · 最常用

| 指令 | 作用 | 备注 |
|---|---|---|
| `/tpa 玩家名` | 请求传送到对方身边 | 对方要 `/tpaccept` 同意 |
| `/tpahere 玩家名` | 请求对方来到你这里 | 同上 |
| `/tpaccept` | 同意别人的传送请求 | |
| `/tpdeny` | 拒绝别人的传送请求 | |
| `/spawn` | 回到主城（服务器出生点） | 所有人都能用的"回家"捷径 |
| `/rtp` | 随机传送到野外找地 | 距离主城 10000～20000 格 |
| `/back` | 回到上次死亡的位置 | 掉装备时救命用 |
| `/warp 地标名` | 传送已设置的地标 | 需管理员先设置 |

### 关于 `/rtp`

- 以主城为中心，随机传送到 **10000～20000 格**之间
- 会自动挑选安全落点，不会掉进岩浆或虚空
- **冷却 30 秒**，短时间内连用会提示"请等待"
- 只对主世界（overworld）生效

## 三、家

| 指令 | 作用 |
|---|---|
| `/homeset` | 在当前位置设家（默认名 home） |
| `/homeset 名字` | 设一个带名字的家 |
| `/home` | 回到默认家 |
| `/home 名字` | 回到指定的家 |
| `/homes` | 列出你所有的家 |
| `/homedel 名字` | 删除某个家 |

> 注意是 `/homeset`，**不是** `/sethome`。这是 Essential Commands 的命名习惯——所有和家有关的指令都以 `home` 开头。
>
> 完整子命令可以用 `/help home` 查。

**家的数量上限按权限分档：普通玩家 1 个，权限提升后 2 个 / 5 个。**
超过上限会提示数量已满。

## 五、语音通话

- 模组：Simple Voice Chat
- 服务端端口：**UDP 13122**
- 需要客户端装了语音模组（v5.3 及以上版本自带）

**使用方法**：

1. 进服后按 **V** 打开语音界面
2. 首次使用会依次要求：选音频输出设备 → 选通话方式 → 绑定按键
3. 有"按键说话"和"音量触发"两种模式

**连不上语音的排查顺序**：

1. 客户端 `game\mods\` 里有没有 `voicechat-...jar`
2. 是不是装了**两个**语音模组（新旧同时存在会冲突）
3. 网络是否封 UDP（换手机热点试）
4. 首次设置是否走完了
5. 麦克风是否被微信 / QQ / Discord 占用

## 七、命令方块速查

### 基本用法

1. `/gamemode creative`
2. `/give @s command_block`
3. 放置后右键编辑命令（**不要加斜杠**）

三种类型：

| 类型 | 触发方式 |
|---|---|
| 脉冲（紫色） | 收到红石信号执行一次 |
| 连锁（绿色） | 跟着上一个命令方块执行 |
| 循环（蓝色） | 持续执行 |

### 常用命令

**传送玩家到指定坐标**：

```
tp @p 1789.5 63 -1387.5 270 0
```

格式：`tp <目标> <x> <y> <z> <yaw> <pitch>`

朝向角对照：

| 方向 | yaw |
|---|---|
| 南 | 0 |
| 西 | 90 |
| 北 | 180 |
| 东 | 270 |

**以玩家身份执行指令**（命令方块不能直接执行玩家指令）：

```
execute as @p run rtp
```

**限制范围**：

```
execute as @p[distance=..2] run rtp
```

注意是 `distance`，**不是** `distances`。

### 悬浮文字

```
/summon minecraft:text_display ~ ~0.5 ~ {text:{text:"第二基地",color:"gold",bold:1b},billboard:"center",shadow:1b,see_through:0b,background:0}
```

- 站在目标方块上输入，`~` 以你脚下为准
- `billboard:"center"` 始终正对玩家
- `background:0` 透明；`1073741824` 是黑底

删除：

```
/kill @e[type=text_display,distance=..3]
```

## 八、常见问题

**Q：`/rtp` 提示"未设置出生点"**
A：管理员先执行 `/spawn set`（站在主城中央）。

**Q：`/rtp` 只能传送一次**
A：30 秒冷却，等一会儿再试。

**Q：`/homeset` 提示数量已满**
A：普通玩家只有 1 个家，删掉旧的 `/homedel 名字` 再设。

**Q：`/sethome` 提示未知指令**
A：服务器装的是 Essential Commands，设家用 `/homeset`，不是原版的 `/sethome`。

**Q：命令方块第一次能用第二次不行**
A：多数是模组冷却，或者方块被设成了"需要红石"而没重新给信号。

**Q：语音没声音**
A：见第五节排查顺序。
