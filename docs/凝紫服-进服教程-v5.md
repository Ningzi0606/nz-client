> 版本：Minecraft **26.3**（Fabric）｜服务器：**play.simpfun.cn:14039**｜上限 20 人  
> 本服是离线（免正版）服：**不需要正版账号**，但要用群里的客户端，并且进服后要注册密码。

## 二、准备客户端

1. 群文件下载 **凝紫客户端-完整版-v5.zip**（约 660MB）；
2. 解压到**英文路径**，例如 `D:\Games\nz`（不要放中文路径、不要在压缩包里直接运行）；
3. 确认目录里有：`凝紫客户端.exe`、`game`、`libraries`、`runtime`。

> 客户端内置 Java 25，**不需要另外装 Java**。

---

## 三、第一次启动

双击 `凝紫客户端.exe`：

1. 弹出启动界面（凝紫服务器 二周目）；
2. 第一次会让你填**用户名**——填你报给管理的名字，**大小写、下划线必须一致**；
3. 客户端会先自动检查更新：
   - 有更新时先弹一个小进度窗「正在更新 x/y」；
   - 没网/连不上 GitHub 会跳过更新，直接进游戏，不影响玩；
4. 第一次启动还会解压游戏资源（约 460MB，进度条走完即可）。

> 名字为什么这么重要：离线服按名字算身份编号，`FocusontheMilky` 和 `focusonthemilky` 是两个人，改名等于换号。

---

## 四、进服 + 注册 + 登录

1. 填好名字 → 点「启动游戏」→ 客户端自动连 `play.simpfun.cn:14039`；
2. **白名单**：没加白名单会直接被踢，提示 `You are not white-listed on this server!`  
   把**准确名字**发给管理，管理执行 `easywhitelist add 你的名字`，立刻生效；
3. 进服后人是被定住的（不能动、不能说话），这是登录插件在拦：
   - 注册：`/register 密码 密码`（两遍，建议 8 位以上）
   - 登录：`/login 密码`
   - 想以后自动登录：`/autologin set 密码`
4. 登录成功后就能正常玩了。

> 顺序不能反：**先加白名单，再进服**；白名单在登录握手阶段就校验，没加连注册界面都看不到。

## 五、皮肤（Quick Skin）

进服后按 **Esc**，点 **Change Skin**（变更皮肤）：

- **导入自己的皮肤**：点 Import，选 64×64 的 PNG；也可以直接把图片拖进窗口；
- **换模型**：Classic（粗手臂）/ Slim（细手臂）；
- **披风**：内置披风或自己导入（支持 GIF 动图）；
- 支持高清皮肤（HD）和透明皮肤。

因为服务器也装了皮肤同步，**你换完，别人马上就能看到**（前提：对方也用群里的客户端；原版客户端只能看到默认皮肤）。

> 顺带：客户端还保留着旧的 CustomSkinLoader（LittleSkin 优先），不用管它，两者不冲突；皮肤以 Quick Skin 选的为准。

## 六、常见问题

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `You are not white-listed` | 白名单没加 / 名字不对 | 把准确名字发管理加白名单 |
| 进服不能动、不能说话 | 没登录 | `/login 密码`；没注册先 `/register` |
| 密码错误 | 记错 / 大小写 | 找管理 `/auth` 重置 |
| 进服是新号、背包空的 | 名字和之前不一致 | 换回原名；不确定让管理查 |
| 提示版本不符 / 模组不兼容 | 没换 v5 客户端 | 重下完整包，别自己加模组 |
| 皮肤没变化 | 没选 / 没同步 | Esc → Change Skin 重新选一次 |
| 启动器打不开、闪退 | 路径有中文、解压不全 | 换英文路径重新解压 |
| 更新卡住 | 网络连不上 GitHub | 等它超时跳过，或挂代理后再开 |

日志位置：
- 启动器：客户端目录 `launcher.log`、`updater.log`
- 游戏：`game\logs\latest.log`

## 七、管理端备忘（玩家可忽略）

| 操作 | 命令 / 方式 |
|---|---|
| 加白名单 | 控制台 `easywhitelist add 名字`（区分大小写，即时生效） |
| 移出白名单 | `easywhitelist remove 名字` |
| 给 OP / 封禁 | `easyop 名字` / `easyban 名字` |
| 重置玩家密码 | `/auth update 名字 新密码` |
| 服务端设皮肤（命令） | `/skin set mojang <正版ID>` / `/skin set web classic "<网址>"` / `/skin refresh` |
| 发客户端更新 | 改文件 → 双击 `一键发布.bat`（GitHub 自动更新清单） |
| 发布说明 | 见 `自动更新-发布说明.md` |

服务端皮肤配置：`/home/container/config/quickskin-server.json`（纹理上限、是否共享给原版客户端等）。
