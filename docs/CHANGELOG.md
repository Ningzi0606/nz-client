# 更新日志（已迁移）

完整更新日志统一放在仓库根目录的 [`../CHANGELOG.md`](../CHANGELOG.md)，本文件只保留一个指路牌。

为什么合并：之前仓库里有两份 CHANGELOG（根目录到 v5.1、`docs/` 这份停在 v5），
加上 `update.json` 的清单版本和整包文件名，同一个客户端出现了"5.1 / 5.2 / 5.3"三套版本口径。
现在以根目录 `CHANGELOG.md` 为唯一来源，玩家能看的简版在 `dist/更新说明.txt`。

- 根目录 [CHANGELOG.md](../CHANGELOG.md)：技术向，按版本记录问题、原因、改法、验证。
- [dist/更新说明.txt](../dist/更新说明.txt)：玩家向，按版本说"你能感觉到什么变化"。
- 版本号规则：`update.json` 的 `version` = 发包时间（如 `20261029.1149`）；
  对外口头叫法是 v5.x，两者的对应关系写在根目录 CHANGELOG 开头的表里。
